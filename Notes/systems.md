# Computer Systems

## Personal Computers:
    a personal computer is much smaller than a mainframe computer , and at early times used by only a single user.
    now with advent of the internet PC's have more than 1 users.
    file protection was introduced with the advent of personal computers.

## Parallel Systems:
    Most systems today are single processor system. a single processor manages all the processes,
    through Time-Sharing by scheduling process in the most optimal way.

## Single-processor systems:
    single processor systems are not fault tolerant as there is only one processor,
    failing of it causes the entire system to halt. 

## Multi-processor systems:
    Multi processor systems have multiple microprocessors or full-fledged processors that talk with each
    other through a bus to share the workload. although the throughput is lesser compared to single 
    processor systems because the multiple processors need to communicate in an efficient and flawless
    way inorder to work optimal, which needs a complex scheduler that introduces some overhead which
    causes delays in responsiveness therefore resulting in lesser throughput

## Real-Time Systems:
    Real time systems are computers that needs to operate within time constraints like automatic pilot
    systems that needs to react to input as quickly as possible , such systems have operating systems
    without virtualization inorder to remove overheads and increase the speed of responsiveness.

## Hard Real-Time systems:
    hard-real-time systems are implemented when the delay needs to be as low as possible , like in
    satellites and other critical systems where time-constraints are a must

## Soft Real-Time Systems:
    soft real time systems are implemented when there can be flexibilities in time constraints like 
    when a system needs to have both the features of full operating systems while also retaining the functions
    of real-time systems

## Distributed Systems:
    Distributed Systems are separate devices connected over local area network , that tends to do different
    jobs with synchronisity.
